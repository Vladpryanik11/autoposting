# Автопостинг роликов студии

Собирает рилсы с основных Instagram-аккаунтов студии (Apify), делает уникальную копию под
каждый аккаунт-сателлит (yt_uniquifier), переписывает подпись (Claude) и заранее ставит
публикации в Postmypost — Instagram, TikTok, YouTube Shorts, по 3 слота в день на аккаунт.
Управление и уведомления — Telegram-бот. Решения по проекту — [DECISIONS.md](DECISIONS.md),
запуск и сервер — [DEPLOY.md](DEPLOY.md).

## Как это работает

```
основные аккаунты ──Apify, раз в час──► ролики на диске (без дублей)
                                             │
     слоты сателлитов на 2 дня вперёд ◄──────┘  свежие первыми; один ролик в разных
                  │                               аккаунтах не ближе 2 ч; источники чередуются
                  ▼
   подпись: без @ и ссылок, рерайт Claude, кодовое слово неприкосновенно
   видео:   своя копия 9:16 на каждый аккаунт, похожесть на оригинал ≤ 0.9
                  │
      сомнение? ──► бот: ✅ / ❌ / ответ новым текстом
                  ▼
   Postmypost: публикация на время слота (±15 мин) → проверка, что вышла
```

Статусы публикации: `PLANNED` → `READY` → `SCHEDULED` → `PUBLISHED`; ветки: `REVIEW` (ждёт
одобрения), `DRAFTED` (режим черновиков), `REJECTED` (отклонена), `RELEASED` (слот упущен — ролик
вернулся в очередь), `FAILED` (3 неудачные попытки, пришло сообщение в бот).

## Первый запуск — коротко
1. Установка — [DEPLOY.md](DEPLOY.md), заполнить `.env` по [.env.example](.env.example).
2. `python main.py serve` (или `start.bat`) — напиши боту `/start`.
3. Бот покажет **шаги запуска**: подтянуть аккаунты из Postmypost → прислать ссылки на рилсы →
   включить боевой режим. Аккаунты начинают публиковать **сразу** (отложить можно в карточке аккаунта).
4. По умолчанию включён **режим черновиков**: посты создаются в Postmypost черновиками. Проверь их
   в кабинете, затем ⚙️ Настройки → 🚀 Боевой режим.

## Основной сценарий: присылаю ссылки
Пару раз в день кидаешь боту ссылки на рилсы — одну, списком или `.txt`-файлом. Бот **сразу**
берёт их в работу (под ответом есть «↩️ Отменить», если ошибся): скачивает, делает копию под каждый
аккаунт и ставит на ближайшее время постов **раньше всего остального**, в том порядке, в каком
прислал. Когда отработает — пришлёт отчёт. Уже скачанные просто поднимаются в начало очереди;
если рилс раньше не скачался — будет новая попытка. Если групп аккаунтов несколько — спросит, в какую.

## Бот
Меню внизу экрана — три кнопки:

| Раздел | Что там |
|---|---|
| 📊 Статус | работает / пауза, сколько в очереди, ближайшие посты; «🗓 Вся очередь» (нажми номер — карточка с «🚫 Не публиковать»), «⏸ Пауза» |
| 📜 История | что вышло: время, аккаунт, ссылка на пост/аккаунт и на оригинал; «📄 Скачать таблицей» |
| ⚙️ Настройки | аккаунты: «Сколько постов в день?» [1–5], своё время, выключить; «🔄 Подтянуть аккаунты»; «📥 Автосбор с аккаунтов» (не обязательно); ошибки |

Бот сам спрашивает только когда в подписи есть призыв к действию, а кодовое слово непонятно:
карточка с видео и кнопками ✅ Опубликовать · ❌ Пропустить · ✏️ Изменить текст.
Режим «только черновики» (для проверки) — из командной строки: `python main.py set drafts on`.

Ссылка на вышедший пост берётся из аналитики Postmypost. Для Instagram Postmypost отдаёт только
ссылку на **профиль** (проверено на живом API), поэтому в истории у Instagram — «профиль» + точное
время выхода; у TikTok/YouTube — ссылка на пост, если Postmypost её отдаёт.

**Проверка.** Посты, которые требуют внимания, приходят карточкой с видео и кнопками
✅ Одобрить · ❌ Отклонить · ✏️ Изменить текст.

Группы: ролики источника из группы `brandA` идут только в аккаунты группы `brandA`.
Один бренд — всё в группе `default`.

Команды для тех, кто любит печатать: `/start` `/status` `/queue` `/help` `/cancel`.

## CLI (то же без бота)
```
python main.py serve | status | tick
python main.py sources add|list|on|off …    python main.py ingest    python main.py posts
python main.py accounts                      python main.py dest sync|list|set …
python main.py set drafts on|off | review auto|cta|all | paused 0|1
```

## Устройство
```
main.py              CLI и запуск
app/config.py        настройки из .env
app/db.py            SQLite: схема (миграции), статусы, журнал событий, очередь уведомлений
app/sources.py       основные аккаунты
app/apify.py         клиент Apify (потолок расходов на каждый запуск)
app/ingest.py        сбор: Apify → база → скачивание (+склейка звука, обновление протухших ссылок)
app/media.py         скачивание, ffprobe, склейка дорожек
app/captions.py      подписи: очистка, кодовое слово, рерайт Claude с проверкой
app/destinations.py  аккаунты: импорт из Postmypost, время постов, группы, отложенный старт
app/planner.py       раскладка роликов по слотам
app/uniq.py          уникализация (yt_uniquifier, случайный профиль на копию)
app/pipeline.py      подготовка → Postmypost → проверка статуса; упущенные слоты; тексты для бота
app/postmypost.py    клиент Postmypost
app/worker.py        рабочий цикл (раз в 20 с), поручения бота, сводка
app/bot.py           Telegram-бот: кнопки, ввод, ссылки на рилсы, уведомления
app/bot_views.py     экраны бота (текст + кнопки)
tests/               python -m pytest  (быстро: -m "not slow")
```

Правка в yt_uniquifier — `patches/yt_uniquifier-rotate-corners.patch`: поворот кадра больше не
оставляет чёрных уголков.
